# Project overlay — minecraft-resource-pack

## Active project target
Minecraft **1.21.1** client resources used by NeoForge mods/resource packs.

## Overrides
- Prove the 1.21.1 `pack_format`, item/model schema, resource paths, shader/sound/font behavior before generating files.
- Later 1.21.x examples are reference-only.
- Repo Textura is the artistic source of truth for project-owned textures/models/visual resources; downstream packs/mod repositories integrate approved exports.
- Preserve native authoring files and provider-specific formats; no silent conversion.

## Authority
Repo Textura/Visual Style Bible for art, `../../VERSION-AUTHORITY.md` for formats/APIs, and the actual downstream resource tree for integration.
