# Project overlay — minecraft-imagegen

## Project role
Use for concept art, concept sheets, look-dev, pack icons, promo images, UI mockups and raster references.

## Overrides
- Repo Textura is the artistic source of truth for project-owned visual assets.
- A generated bitmap is **not** automatically a production texture, UV layout, model source or provider-native asset.
- Preserve `.bbmodel` and other authoring sources; do not silently convert between GeckoLib/AzureLib/EMF/CEM/Animated Java/CPM/Epic Fight pipelines.
- Final production assets require the applicable art-direction, Blockbench/provider and visual-QA workflow.

## Authority
Visual Style Bible, asset contracts, Repo Textura source assets and provider-native rules override generic image-generation suggestions.
