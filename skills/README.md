# Skills e instruções especializadas — Minecraft Mod Factory

Esta pasta é o ponto de entrada para instruções reutilizáveis da Factory. Ela não transforma documentação versionada em API de runtime.

Leia primeiro `ROUTER.md`, `VERSION-AUTHORITY.md` e, quando houver ação manual do usuário, `USER-GUIDED-WORKFLOW.md`.

## Authority routing

- Engenharia e integração reutilizável: `../engineering/`.
- Direção artística e asset pipeline: `../art/`.
- Runtime de cada mod: repositório próprio do mod.
- Presença/versão física de providers: modlist/JAR mais recente, externa à Factory.

A biblioteca histórica de skills em `Gustavaopere/neoforge-rpg-skilltree` continua sendo origem de migração. Conteúdo ainda não classificado/migrado pela matriz não é considerado presente na Factory apenas porque existia no repositório histórico.

Preserve payload-fonte, autoria, licenças e overlays quando uma skill for migrada. Exemplos multi-versão nunca substituem evidência de Minecraft 1.21.1 / NeoForge 21.1.248.
