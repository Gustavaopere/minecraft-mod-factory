# Project overlay — minecraft-jar-reverse-engineering

## Active project target
Minecraft **1.21.1 / NeoForge 21.1.x / Java 21** providers and mods.

## Overrides
- Inspect only the exact JAR/build actually present when resolving API, metadata, mixin, registry or provider behavior.
- Prefer source and official exact-version documentation when available; decompilation is evidence, not license to copy implementation.
- Record mapping/version uncertainty explicitly.
- Do not infer a newer API from a latest-version JAR or website.
